# حاشية — تجربة iPhone وiPad

تطبيق دراسة محلي، مجاني بدون سيرفر. هذه نسخة تجريبية وليست إصدار المتجر.

## الميزات
- حركة افتتاحية فاتحة مع احترام تقليل الحركة وBy Ahmad Al-awi.
- مكتبة وأقسام، تسمية ونقل ومفضلة، استعادة وحذف نهائي للملف وملحقاته.
- PDFKit مع PencilKit للقلم واللمس، نص حر قابل للتعديل، انتقال برقم الصفحة وملاءمة العرض.
- حاشية نصية وتسجيلات صوت مرتبطة بالصفحة، وتصدير PDF بالتعليقات.
- Quick Look لمعاينة Office مع حفظ الأصل؛ ZIPFoundation لاستخراج الفيديو المضمّن إلى مشغّل مستقل.

## القيود
- Office ليس محررًا قابلًا للتعليق حاليًا؛ لا ضمان لمطابقة جميع الخطوط أو الحركات.
- استخراج الوسائط لـPPTX/DOCX/XLSX فقط؛ الروابط الخارجية ليست فيديو مضمّنًا.
- تحويل خط اليد إلى نص والتبويبات المتعددة والأشكال الهندسية لم تكتمل.
- توافق كل قلم وحفظ القلم أثناء التكبير ودوران الصفحات والتسجيل الصوتي يحتاج اختبار جهاز فعلي.
- ملف Hashiya-unsigned.ipa يحتاج توقيعًا بشهادة مناسبة قبل التثبيت؛ لا ينزل على الجهاز بالضغط عليه فقط.
- لا شهادات ولا مفاتيح توقيع في المستودع، ولم يرفع شيء إلى TestFlight أو App Store.

## البناء والاختبارات
GitHub Actions يبني على محاكي آيفون وآيباد، ويصدر صور UI، ويبني تطبيق arm64 للجهاز ويغلفه كـIPA غير موقّع. انظر STATUS.md وآخر نتائج Actions للحالة الفعلية.
