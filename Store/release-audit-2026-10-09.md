# Tayya 0.4.2 (10) — candidate

Apple rejection checked October 9: 2.1(a), build 0.4.1 (9), iPad Air 11-inch (M3). The reviewer cannot access all features and requests credentials or a full demonstration. No specific feature was identified. The app has no accounts.

An explicit first-launch local demonstration choice now opens actual editable sample documents. Four labeled toolbar groups replace the document ellipsis menu; margin actions are also visible. Root library defaults to unfiled documents; moving into a section removes a card from root and keeps it in its section, with an explicit All view.

PDF deletion remaps zero-based ink/text/OCR and one-based card/audio/margin links. Independent margins linked to a deleted PDF page become general notes. Deleted page-specific content is retained in a disk snapshot. A pending transaction restores before any PDF read after termination; undo rejects changed resources to protect newer writing. Margin deletion retains page UUID/text/ink in a recoverable trash index. One page must remain in each notebook/margin. Backups include both deletion archives.

Validation and upload are pending. Existing native engine, privacy and encryption behavior are unchanged.
