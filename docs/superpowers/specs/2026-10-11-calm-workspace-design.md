# Tayya calm workspace

User approved the light quiet-desk visual preview and explicitly instructed implementation, routine autonomy, removal of unhelpful/nonfunctional options, recording isolation, and attention to navigation/alignment. Continue without redundant stage approvals.

## Outcome
Retain the native SwiftUI app and all user files. Make library, document, independent margins and study tools understandable on iPhone and iPad. Warm near-white surfaces, forest-green selection, modest corners, real document thumbnails, fixed labeled writing tools, compact navigation and restrained contextual controls. Preserve dark-mode readability.

## Behavior
- Library: compact previews, readable filenames, recent/resume entry, explicit create/import, phone bottom destinations (library/sections/review/settings), tablet sidebar. Trash, backup and sample access remain discoverable. Moving retains root/section semantics.
- Document: compact writing controls and page navigation, clear pages/study/files access, no essential action hidden behind ellipsis. Margins opened only by an explicit margin/split action. Page deletion/undo/recovery protections remain.
- Audio: recording starts/stops without opening, closing or resizing a margin, even after permission prompts or denial. One obvious recording entry and recording history; retain access to existing per-page recordings. No data deletion disguised as feature removal.
- Language/OCR: remove unsupported language choices and empty placeholder features; surface only OS-supported recognition languages. Preserve functional local recognition/search. No new translations or external AI.
- Margins: independent navigation/add/delete/recover/expand, compact labeled controls, stable ink geometry and optional page links in page management instead of a crowded footer.
- Reuse stable accessibility identifiers. Verify actual native add/edit/delete/recover/relaunch, microphone denial, navigation, rotation and ink visibility. No claims of universal bug freedom.

## Constraints
iOS 17+, iPhone/iPad, Arabic RTL, no paid dependencies, no accounts/server/analytics, no changing original documents or review submissions during development. New candidate 0.5.0 (11). Native validation requires macOS CI; local Linux checks are limited.
